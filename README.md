# Python Base — интерактивный справочник

Независимый статический сайт по материалам конспекта Python.

## Открыть локально

Откройте [index.html](index.html) двойным щелчком в браузере. Для поиска, навигации и отображения материалов установка зависимостей не нужна.

## Состав

- `index.html` — разметка сайта;
- `styles.css` — адаптивный дизайн для компьютера и телефона;
- `app.js` — данные, поиск, фильтрация методов и навигация.

## Публикация

Это статический сайт: его можно разместить на GitHub Pages, Vercel, Netlify или любом обычном хостинге. После публикации сайт будет доступен по постоянной ссылке с любого устройства.
